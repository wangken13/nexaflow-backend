## 采购边界

1. 当前是 Docker Compose 单机生产基线，不宣称多可用区容灾或 Kubernetes 自动扩缩容。
2. 正式 SLA、数据驻留、培训和迁移范围应写入客户合同；试用环境不等同正式 SLA。
3. 支付、短信、邮箱、微信和 WhatsApp 等外部渠道必须由购买企业提供合法账号与授权。
4. AI 输出始终是辅助草稿，最终价格、交期与合同承诺必须由授权人员确认。
